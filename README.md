## 📦 Installation

Run directly without installing using `npx`:

```bash
npx kkhay-cli --help
```

Or install globally via npm:

```bash
npm install -g kkhay-cli
```

## 🔑 Configuration

Configure your gateway API key from the [K Khay Gateway Dashboard](https://gateway.kkhay.com/dashboard/keys):

```bash
kkhay config set apiKey kkhay_live_your_key_here
```

Inspect your current configuration:

```bash
kkhay config get
```

Or export environment variables in your shell:

```bash
export KKHAY_API_KEY="kkhay_live_your_key_here"
export KKHAY_BASE_URL="https://api.kkhay.com"
export KKHAY_IPN_SECRET="whsec_your_webhook_secret_here"
```

## 🚀 CLI Commands

### 1. Create an Invoice (with terminal QR code)

Generate an invoice for USDT on BNB Smart Chain (BSC), Solana, Bitcoin, or any supported token:

```bash
# Example: USDT on BNB Smart Chain
kkhay invoice create \
  --amount 49.99 \
  --network bsc \
  --token USDT \
  --title "Annual Pro Plan" \
  --order-id "ORD-9842"
```

```bash
# Example: Native Solana or Bitcoin
kkhay invoice create \
  --amount 25.00 \
  --network solana \
  --token SOL

kkhay invoice create \
  --amount 120.00 \
  --network bitcoin \
  --token BTC
```

Flags available on `kkhay invoice create`:
- `-a, --amount <number>`: Price amount to charge (required)
- `-n, --network <string>`: Blockchain network (e.g. `bsc`, `polygon`, `base`, `arbitrum`, `solana`, `bitcoin`, `ton`, `tron`)
- `-t, --token <string>`: Payment token symbol (e.g. `USDT`, `USDC`, `BTC`, `ETH`, `SOL`, `TON`, `BNB`)
- `-c, --currency <string>`: Base currency code (default: `USD`)
- `--type <type>`: `PAYMENT` (default), `DONATION`, or `SUBSCRIPTION`
- `--order-id <id>`: Internal gateway order ID reference
- `--title <title>`: Product or service title
- `--customer-name <name>`: Customer name
- `--customer-email <email>`: Customer email address
- `--redirect-url <url>`: Success return URL
- `--cancel-url <url>`: Cancel return URL
- `--ipn-url <url>`: Custom webhook IPN callback URL
- `--no-qr`: Skip rendering terminal ASCII QR code

---

### 2. Inspect an Invoice

Fetch the real-time status, deposit address, exchange rate, and on-chain blockchain confirmations:

```bash
kkhay invoice get 01940000-0000-7000-8000-000000000001
```

---

### 3. List Gateway Invoices

Display recent invoices generated by your gateway account:

```bash
# List last 10 invoices
kkhay invoice list --limit 10

# Filter by status (WAITING, PAID, EXPIRED, CANCELED)
kkhay invoice list --status PAID --limit 20
```

---

### 4. Trigger Simulated Signed Webhooks (IPN)

Simulate a production HMAC-SHA256 signed webhook without sending real crypto. Verifies your webhook endpoint against the exact `x-kkhay-signature` payload:

```bash
kkhay trigger payment.paid \
  --forward-to http://localhost:3000/api/webhooks \
  --amount 50.00 \
  --token USDT \
  --network bsc
```

---

### 5. Check Gateway Connection Status

Verify your network connection and test your API key authentication with K Khay Gateway:

```bash
kkhay status
```
